# PlaylistPro para macOS

Downloads do **PlaylistPro Desktop** para Mac, o player de rádio indoor da
[Fabricca Multimídia](https://www.fabriccamultimidia.com.br/).

Este repositório existe apenas para distribuir os instaladores. O código-fonte
é privado. A versão para Windows está em
[playlistpro-desktop-releases](https://github.com/fabriccaradio/playlistpro-desktop-releases/releases/latest).

## Baixar

Pegue a versão mais recente em **[Releases](../../releases/latest)**: o arquivo
`PlaylistPro-<versão>.dmg`.

## Instalação

1. Abra o `.dmg` e arraste o **PlaylistPro** para a pasta **Aplicativos**.
2. Abra o PlaylistPro pela pasta Aplicativos. Na primeira vez ele termina a
   instalação sozinho e abre o player.

Como o app ainda não é assinado nem notarizado pela Apple, o macOS bloqueia a
primeira abertura. Para liberar: **Ajustes do Sistema** → **Privacidade e
Segurança** → em *Segurança*, **Abrir Mesmo Assim** ao lado do aviso do
PlaylistPro, e confirme com a sua senha. Isso só é preciso uma vez; as
atualizações seguintes chegam sozinhas.

## Requisitos

- Mac com Apple Silicon (M1 ou mais novo). Macs com processador Intel não são suportados.

## Suporte

Fale com a Fabricca Multimídia pelos canais em
[fabriccamultimidia.com.br](https://www.fabriccamultimidia.com.br/).
